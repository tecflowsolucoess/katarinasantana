# DK Beauty - Mídia Kit

Landing Page premium desenvolvida com HTML5, CSS3 e JavaScript puro.

## Estrutura do Projeto
- `index.html`: Arquivo principal HTML.
- `css/`: Folhas de estilo (style, animations, responsive).
- `js/`: Scripts (main, animations, gallery).
- `assets/`: Imagens, ícones, logos e vídeos.
- `fonts/`: Fontes personalizadas.
